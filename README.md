# Polina Lemenkova

Researcher in geoinformatics and Earth observation. This account hosts the
source code accompanying my scientific publications: scripts, data and figures
for reproducible processing, analysis and cartographic visualisation of
geospatial data. Repositories are named by method and study area and are linked
to the corresponding peer-reviewed articles.

## Research areas

- Satellite image processing and land-cover classification from Landsat OLI/TIRS time series
- Machine-learning classification for remote sensing (Random Forest, SVM, MLP/ANN, Decision and Extra Trees, gradient boosting)
- Marine geophysics, bathymetry and geomorphometry of ocean trenches
- Cartographic scripting, terrain modelling, seismology and geohazard assessment
- Reproducible processing pipelines and cloud geoprocessing (Google Earth Engine, PySpark)

## Languages and software

Python, R, Octave/MATLAB, Shell (bash, AWK).
GMT and pyGMT, GRASS GIS, GDAL/PROJ, QGIS, scikit-learn, ObsPy, rasterio, terra,
earthpy, ggplot2, seaborn, Google Earth Engine, Apache Spark (PySpark).
